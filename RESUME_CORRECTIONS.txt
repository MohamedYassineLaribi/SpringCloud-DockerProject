================================================================================
                        STRUCTURE DU PROJET
================================================================================

6 MODULES SPRING CLOUD:

1. classe-microservice (Port 8080)
   - Gestion des classes
   - Base H2 en mémoire
   - Config Server + Eureka Client

2. etudiant-microservice (Port 8081)
   - Gestion des étudiants
   - Communication avec classe via OpenFeign
   - Base H2 en mémoire

3. eurekaserver (Port 8761)
   - Service Discovery
   - Dashboard: http://localhost:8761

4. configserver (Port 9999)
   - Configuration centralisée
   - Mode native (classpath)

5. gatewayserver (Port 8888)
   - API Gateway
   - Routage automatique via Eureka

6. config-repo
   - Fichiers de configuration YAML
   - Profils: default, prod, qa

================================================================================
                        SOLUTIONS AUX PROBLÈMES IDE
================================================================================

Si l'IDE affiche des erreurs Lombok (builder(), getters, setters):

1. Nettoyer et recompiler:
   mvn clean install

2. Recharger le projet dans l'IDE:
   - Fermer et rouvrir l'IDE
   - Ou: Maven → Reload Project

3. Installer le plugin Lombok:
   - IntelliJ: Plugins → Rechercher "Lombok"
   - Eclipse: Exécuter lombok.jar

4. Activer annotation processing:
   - Settings → Compiler → Annotation Processors
   - Cocher "Enable annotation processing"

💡 Note: Maven compile correctement même avec ces erreurs IDE !
